# Interferência — camada transparente

Página para criar uma barra animada, outros estilos VHS/CRT e emojis opcionais. A saída é transparente, sem vídeo ou fundo verde.

1. Abra a página hospedada e ajuste o efeito. O padrão é somente uma barra descendo.
2. Clique em **Copiar link**. O endereço leva as configurações na própria URL.
3. No TikTok LIVE Studio, adicione uma fonte **Link / Navegador** e cole o endereço. Não use captura da janela de prévia: uma janela normal do navegador não transmite transparência.
4. Ajuste o tamanho e mantenha a fonte acima do vídeo. Cada alteração exige copiar e atualizar o link da fonte.

A prévia xadrez indica transparência e não é incluída na camada. A fonte de navegador precisa ser compatível com transparência; a cor de fundo que um navegador normal exibe não comprova se o alfa está sendo transmitido. Se o link começar com `file://`, hospede a pasta como site estático para obter uma URL HTTPS compatível com fontes que não abrem arquivos locais. Os emojis são decorativos e não representam interações reais.
