# Interferência — VHS, CRT e emojis

Página local ou estática que gera uma camada de interferência e emojis, sem fazer upload de vídeo. Abra `index.html` no navegador ou publique a pasta como site estático.

1. Configure modelo, intensidade, cor, espessura e velocidade.
2. Opcionalmente, ative emojis e escolha símbolos, direção, tamanho, velocidade e quantidade.
3. Escolha o fundo verde, azul ou preto e clique em **Abrir efeito**.
4. Capture a janela **Interferência — captura** no software de transmissão. Para eliminar o verde ou azul, aplique o filtro chroma key no software de captura.

As configurações são guardadas no navegador e sincronizadas entre a tela de controle e a janela de captura quando o armazenamento local estiver disponível. Em `file://`, a política de armazenamento pode variar entre navegadores; hospedar como site estático é a opção mais previsível. A janela de captura deve permanecer aberta; se o navegador bloquear pop-ups, permita-os. A página não transmite conteúdo por conta própria.

Os emojis são elementos decorativos, não representam eventos ou pessoas reais. A compatibilidade de captura, desempenho e chroma key depende do navegador e do software utilizado.
